# 天喜引擎（TX-Oracle）

天喜點樣出預測：Elo 打底 + LightGBM 排先後 → 首場前 90 分鐘全日凍結 → 賽後只對帳唔改數。
模型版本／參數屬 `status: observation`：以源碼同公開 API 為準，唔當永久事實；冇任何命中率數字（對外戰績以 https://tianxi.racing/track-record 即時為準）。

## 結論

- 2026-10-20 · 天喜引擎（TX-Oracle v3；公開 engine-health 標示「TX-Oracle v3.2」）係兩層集成：LightGBM LambdaRank 學「同場邊匹排前」，天喜 Elo v12 用馬／騎師／練馬師長期實力做獨立後備；兩邊喺同一場內各自標準化，再按 α 混合。〔MODEL.md §1；ARCHITECTURE_AND_PAPERS.md〕
- 2026-10-20 · α 預設 0.88；每個賽馬日自動跑健康閘，閘 FAIL 就 α＝0，只出 Elo（較保守後備）。〔MODEL.md §1；ARCHITECTURE_AND_PAPERS.md；manual.tsx 答客問〕
- 2026-10-20 · 臨場獨贏賠率永不進入排序模型，只喺選馬頁作「市場對照」欄。〔ARCHITECTURE_AND_PAPERS.md；engine-health「臨場盤不入 LGB」〕
- 2026-10-20 · 凍結規則：每賽日首場開跑前 90 分鐘（T−90，即 T−1.5h）一次過凍結全日四揀及第五選；鎖後只接官方名次同派彩重算對帳，唔改凍結預測。〔tianxi-web README；EngineLanding.tsx；engine-health lockPolicy〕
- 2026-10-20 · 未鎖＝「初版」（可能隨刷新改）；鎖咗＝「最終版」。戰績同命中率只計最終版凍結四揀，初版唔入帳。〔engine-health publicRule；manual.tsx；predictor.tsx〕
- 2026-10-20 · 主指標係「四揀平均命中匹數」，目標 3／4；README 寫明市場熱門 2.31 只作對照，**唔宣稱已達標**，負數如實展示。〔tianxi-web README；blueprint 2026-10-13〕
