# 天喜賽馬吉祥物

天喜賽馬嘅官方吉祥物：一隻胖嘟嘟、笑容燦爛嘅啡色卡通馬，著天喜綠金色騎師綵衣。

## 設計要點
- 企身、兩腳行；手係圓形深啡色馬蹄，冇手指
- 大圓眼、白色鼻紋、深啡色鬃毛同馬尾
- 綵衣：翠綠色配金色菱形；頭盔：綠金間條；心口金色馬蹄頸鏈
- 主色：翠綠、暖金、啡、深啡
